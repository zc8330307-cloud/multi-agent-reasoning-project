# 多 Agent 长链推理工作流设计

## 1. 项目目标

本项目用于演示一个基于长链推理和多 Agent 协作的智能项目辅助系统。系统可以围绕一个复杂任务，自动完成任务拆解、资料整理、代码分析、测试验证、文档生成和结果审查。

## 2. Agent 分工

| Agent | 主要职责 |
|---|---|
| 任务规划 Agent | 理解用户目标，拆解长链任务，生成执行计划 |
| 资料整理 Agent | 整理项目背景、应用价值和使用场景 |
| 代码分析 Agent | 扫描项目结构，提出代码优化建议 |
| 测试验证 Agent | 检查中间结果是否完整，形成反馈 |
| 文档生成 Agent | 生成项目说明、工作流说明和总结内容 |
| 结果审查 Agent | 检查最终输出是否完整、规范、闭环 |

## 3. 长链推理流程

```text
需求理解
  ↓
任务拆解
  ↓
多 Agent 分工执行
  ↓
中间结果汇总
  ↓
测试验证
  ↓
反馈修正
  ↓
最终输出
```

## 4. Token Plan

项目将 Token 预算分配给不同阶段，避免复杂任务一次性处理导致上下文混乱。规划阶段用于任务拆解，分析阶段用于代码和资料处理，验证阶段用于检查反馈，文档阶段用于最终整理，审查阶段用于质量控制。

## 5. 可扩展方向

1. 接入真实 LLM API，让每个 Agent 调用不同模型能力。
2. 增加前端可视化界面，展示多 Agent 执行链路。
3. 增加项目文件读写能力，实现自动修改代码。
4. 增加更完整的测试框架，提升工作流可靠性。
